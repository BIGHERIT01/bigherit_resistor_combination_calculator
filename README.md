#BigHerit Resistance Calculator

What it does

BigHerit Resistance Calculator is a Python program that calculates the total resistance of resistors connected in series and parallel.

It also compares resistor values by identifying the highest resistance, lowest resistance and average resistance.

How to run it

1. Install Python 3.
2. Download the Python file.
3. Open the file using a Python editor such as Pydroid 3.
4. Run the program and select an option from the menu.

Features

- Calculates total resistance in series.
- Calculates total resistance in parallel.
- Identifies the highest resistor value.
- Identifies the lowest resistor value.
- Calculates the average resistance.
- Allows users to perform multiple calculations.
